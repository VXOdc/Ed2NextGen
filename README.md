# Ecosystem Overview

This monorepo bridges advanced edge computational workflows with modern human coordination infrastructure. It houses two primary flagship core components:

1. **Manta:** An experimental, local-first domain-specific language (DSL) engineered for AI perception, computer vision workflows, and low-latency robotics orchestration.
2. **Ed2NextGen:** A lightweight, high-performance static web platform built for decentralized volunteer tracking, open-source resource library indexing, and community recognition pipelines.

---

# 1. Manta DSL

**Manta** simplifies complex AI perception loops. Instead of writing heavy boilerplate initialization scripts in Python or C++, Manta allows you to write clean, declarative syntax that compiles directly to runtime-optimized TypeScript.
